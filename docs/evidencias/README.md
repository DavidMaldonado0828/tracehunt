# Evidencias de verificación

Este directorio está reservado para evidencias reproducibles de tareas completadas, como resultados de pruebas, capturas o instrucciones breves para repetir una validación. Cada evidencia debe indicar la tarea del Workplan relacionada y el comando o procedimiento utilizado; no se debe registrar como superada una verificación que no se ejecutó.

El archivo vacío `.gitkeep` conserva este directorio en Git mientras todavía no haya evidencias. No representa una prueba ni una funcionalidad implementada.
